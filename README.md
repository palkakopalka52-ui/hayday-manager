# Hay Day · Фермы

Менеджер ферм Hay Day для Windows. Карточка привязана к конкретному экземпляру BlueStacks 5. Менеджер распознаёт игровое окно, собирает и пересевает пшеницу и выставляет излишки в придорожном киоске.

## Сборка и запуск

Нужны 64-разрядная Windows с .NET Framework 4.x, BlueStacks 5 и 64-разрядный Python 3.12 с доступной командой `py -3.12`. В PowerShell из корня репозитория выполни команды.

```powershell
py -3.12 -m pip install --target .\vision-packages -r .\requirements.txt
.\Build.ps1
.\HayDayManager.exe
```

## Настройка фермы

1. Подключи существующий экземпляр BlueStacks или создай его через «Создать». Открой Hay Day и войди в игру вручную.
2. На карточке отметь «Отдельная тестовая ферма». Открой «Калибровка» → «Снять окно Android» и следуй подсказкам для области поля, ориентиров, инструментов и ячеек киоска.
3. Настрой размер партии, цену и бесплатное объявление. Для пустого поля нажми «Старт с пустого поля». Для растущей или спелой пшеницы нажми «Продолжить посевы».
4. Нажми F9 или «Стоп», чтобы остановить цикл. При ошибке кнопка «Снимок сбоя» открывает сохранённый кадр.

Менеджер хранит карточки, калибровку и диагностические снимки локально в папке `data`. Фермы хранятся в экземплярах BlueStacks.
